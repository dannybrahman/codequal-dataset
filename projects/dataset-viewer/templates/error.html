📋 Setup Instructions

To use the CodeQual Dataset Viewer, make sure you have:

  1. Set the DATASET_PATH environment variable to point to your integrated dataset directory
  2. The dataset directory contains train.jsonl, valid.jsonl, and test.jsonl files
  3. The dataset was properly integrated using the CodeQual dataset integration workflow
Example setup:
# Copy the example environment file
cp .env.example .env

# Edit .env to set your dataset path
DATASET_PATH=../dataset/generated/integrated/codesearchnet

# Install dependencies
pip install -r requirements.txt

# Run the application
python app/app.py
